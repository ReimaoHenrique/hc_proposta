## O que o sistema deve permitir

- Manutenção preditiva
- Manutenção baseada em condição
- Monitoramento remoto
- Gestão de ativos
- Redução de downtime
- Redução de custos
- Aumento da disponibilidade operacional

## Objetivo principal

**Trocar componentes antes da falha ocorrer.**

A inteligência artificial visa prever falhas, gerando notificações antecipadas para que as peças sejam trocadas antes que deem defeito. A vida do gerador fica toda registrada no banco de dados a partir do momento em que é ligado.

## Software do ecossistema

| Software | Função |
| --- | --- |
| **HC Guardian** | Ecossistema completo (hardware + software + IA + cloud) |
| **RHINOS** | Ferramenta de diagnóstico desktop (Rust + Tauri + OBD2) |
| **ARGUS** | IA de colmeia — observa a frota inteira |
| **SENTRY** | IA unitária — observa cada gerador individualmente |
| **HC Generators** | Geradores próprios da HC, já integrados ao ecossistema |

## Diferença competitiva

Não é apenas um produto de monitoramento: é uma **empresa de tecnologia industrial** com Industrial AI + IoT + SaaS + Hardware, onde o valor real está na previsibilidade operacional criada pelo acúmulo de dados.
