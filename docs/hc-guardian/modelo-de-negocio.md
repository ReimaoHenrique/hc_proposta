## Serviço SaaS

O ecossistema é um **serviço SaaS** que visa utilizar o software nos próprios geradores da HC, denominados **HC Generators**, além de ser oferecido como plataforma para frotas de terceiros.

## Ciclo de valor

O ciclo de aprendizado contínuo é o núcleo do plano de negócios:

**Geradores → Dados → Digital Twin → IA → Menos Falhas → Mais Clientes → Mais Dados → IA Melhor → Mais Valor**
